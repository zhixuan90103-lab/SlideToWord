# 划词手势设计

对照 Word Search Pop 主模式。商业化（道具/广告）不在范围内。

## 从 BUG 抽出的规则

| # | 现场 | 根因 | 设计 |
|---|------|------|------|
| 1 | 横竖能划，斜着几乎划不动 | 用「手指进了哪个矩形格」锁方向。斜走时先踩到右/下格，方向被锁成横或竖 | **方向来自起点中心→手指的向量**，量化到 8 个 45°。禁止用第一格邻居锁方向 |
| 2 | 斜划超前一格（指在 I，线已到 T） | 投影用横竖格宽去除。对角一步像素是 `(cell,cell)`，`|step|²=2`，结果被算成 2 格 | **步长按格子步向量归一**：`along = dot(δ, step) / (cell · \|step\|²)`。对角一步 = 1 |
| 3 | 线跟手抖 / 贴格边闪 | 每帧按矩形包含重算整条路径 | 走出死区后 **锁八分位**；角度不够不换向 |
| 4 | 线一格一格跳，不像 Pop | 预览线只画到「当前选中格中心」 | **看见的条**跟手指在射线上的位置连续伸缩；**算进词的字母**仍按最近中心 |

命中坐标用普通 `clientX/Y`（映射到格子网格）。不要用 iOS `preciseLocation` 做进格（Apple：Do not use for hit testing）。

## 一次手势

```
down  → 按下格 = 起点；方向未锁
move  → 距起点中心 < slop：仍只有起点
      → 否则 atan2 量化到 45°（已锁则滞后换向）
      → 手指投影到该射线：along 为小数（画线用），round(along) 为选中格
up    → 线段字母 ∈ 词表（正反）则收下；否则丢弃
cancel→ 与 up 丢弃相同
```

词必须是一条直线（横 / 竖 / 斜）。不是 Two Dots 式拐弯。

## 常数（`src/game/swipeDesign.ts`）

| 名 | 值 | 作用 |
|----|-----|------|
| `LOCK_SLOP_CELLS` | 0.42 | 小于此距离不锁方向，避免邻格抢锁（BUG 1） |
| `OCTANT_HOLD` | 0.38 × 45° | 已锁方向的换向滞后 |
| `ALONG_ROUND` | 最近中心 | 跟手；斜向必须用归一化步长（BUG 2） |
| 线宽 | 0.72 格 | 画在中心之间 |

改手感只改该文件，不要在 `mount.ts` 里再写一套投影。

## 三层反馈（不移动棋盘）

| 阶段 | 看见 | 震动 |
|------|------|------|
| 按下 | 起点立刻盖上绿胶囊；该字母略放大、变白；上方出现当前字母 | 轻点（selection） |
| 滑动 | 绿条沿锁定方向跟手伸长；每新纳入一个字母：字母弹一下、预览字更新并弹一下 | 每新字母一次轻点 |
| 抬手成功 | 绿条收成彩色固定条；词表该项划掉并弹一下；预览消失 | 成功 |
| 抬手失败 | 绿条和预览收回消失；盘面不动 | 无（不惩罚） |
