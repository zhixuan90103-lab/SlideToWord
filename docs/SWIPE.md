# 划词手势设计

对照 Word Search Pop 主模式。商业化（道具/广告）不在范围内。  
总规范：[CONVENTIONS.md](./CONVENTIONS.md)。意图：[INTENT.md](./INTENT.md)。实现投影只放 `src/game/swipeDesign.ts`；`mount.ts` 只画、不投影。

下列常数是**本关手感设计**，不是 iOS 官方推荐。Apple 只给触点；`UIPanGestureRecognizer` / `isDirectionalLockEnabled` 不规定 8 向换向角度。

## 线头怎么量（正确行为）

1. **方向只有 8 条固定直线**（横、竖、45° 斜）。条不拐弯。  
2. **起点**是按下那一格的中心，整次手势都从这儿量。  
3. 手指在动，**每一样本**都用**此刻**的屏幕坐标重算。不是「只有换向才量」，也不是量手指到起点的斜线距离。  
4. 线头 = 从起点沿**当前这一条**直线，走到离手指最近的点。手指不在线上时，头仍在线上，不离开射线去粘指尖。  
5. 换向 = 换成另一条直线，再用同一起点、此刻手指，在**新线**上量最近点。不得沿用上一档的长度数字。  
6. 画线用这一帧的 `step` 和 `along`。`along` 是格子步：对角一步是 `(1,1)`，不是单位圆。

找对留下后，两端钉在格心。滑动中线头不必停在格心。

## 几何（对齐）

- 格子、字母、线的端点用**同一套格子中心**：`(列 + 0.5, 行 + 0.5)`。
- 色条 SVG 与格子区内边距同一套 `--ws-pad-*`（默认 5 / 5），和字母同一块区域。
- 字母默认 **35px**。条距格心 0.3 格（`floor(along + 0.3)`）后该格才白并放大 **1.28**；线上其余已触发的格只白。观感默认见 [TUNE.md](./TUNE.md)。
- 画线：起点中心 + `step * along`。`step` 分量只在 `{-1,0,1}`。禁止单位圆（BUG 5）。禁止换向沿用旧 `along`（BUG 6）。
- 未过粘住角：方向不变。一过门槛：瞬间切到新格步。快滑只靠更大粘住角防抖。

## 一次手势

```
down  → 按下格 = 起点；方向未锁；画出本次色（不透明）
move  → 死区：字母不外扩，条跟角度
      → 未到第二字（along < 1）：8 向立刻切，不辅助
      → 到达第二字：定方向，之后才粘住 / 贴向；过门槛瞬间切
      → 每样本：用此刻手指在当前射线上的最近点更新 along（画线）；round(along) 为预览收字
up    → 用松手点再投影；字面命中或意图终点门命中则留下细一档的条；否则丢掉
cancel→ 丢掉，不走成交
```

词必须是一条直线（横 / 竖 / 斜）。不是 Two Dots 式拐弯。  
角度始终是 **起点中心 → 手指**，不是线头再拐。缩回死区会清掉方向，再滑出去重新选。

## 设计常数（`src/game/swipeDesign.ts`）

| 名 | 值 | 设计意图 |
|----|-----|----------|
| `LOCK_SLOP_CELLS` | 0.45 格 | 区内不收字、方向清空。条仍按手指角度微伸（`along` 作画线 hint） |
| `COMMIT_DIR_CELLS` | 1 格 | 第二字中心。此前 8 向自由立刻切；到达后才定方向并辅助 |
| 8 向间隔 | 45° | `atan2` 量化。相邻方向中线在 ±22.5° |
| `OCTANT_HOLD_LOOSE` | 45° × 0.52 ≈ 23° | 已定方向且速度 &lt; 10 格/秒：刚过中线就切 |
| `OCTANT_HOLD` | 45° × 0.62 ≈ 28° | 快滑粘住下限 |
| `OCTANT_HOLD_FAST` | 45° × 0.25 ≈ 11° | 叠在 28° 上，随速度插值加高 |
| `ASSIST_SPEED_CELLS_PER_SEC` | 10 | 低于此用松粘住；达到此才用快滑粘住 |
| 速度慢 / 快 | 4 / 16 格/秒 | `speedBlend` 两端；也用于终点门插值 |
| 终点门慢 欠/过 | 0.48 / 0.38 | 慢滑「3 字多一点」不成 4 字词 |
| 终点门快 欠/过 | 0.95 / 1.25 | 快滑过冲仍能收 |
| `LINE_WIDTH_CELLS` | 0.75 格 | 滑动中（含按下未滑出时的圆）直径 |
| `COMMIT_LINE_WIDTH_CELLS` | 0.7 格 | 抬手找对后留在盘上的直径 |

画线与当前射线 `along` **同步**（无长度缓动）。每样本重算；换向用新 `step` 重投影。

改手感只改该文件里的常数，不要在 `mount.ts` 再写一套投影。

## 颜色

- 按下时从调色板随机取色；**排除盘上已留下的颜色**。调色板用尽则再从全表抽。
- 滑动中与找对留下用同一次颜色；失败丢掉，不占色。

## 从 BUG 抽出的规则（历史，勿退回去）

| # | 现场 | 根因 | 设计 |
|---|------|------|------|
| 1 | 横竖能划，斜着几乎划不动 | 用「手指进了哪个矩形格」锁方向 | **方向来自起点中心→手指**，量化到 8 个 45° |
| 2 | 斜划超前一格 | 对角用横竖格宽去除，一步被算成 2 | `along = dot(δ, step) / (cell · \|step\|²)`。对角一步 = 1 |
| 3 | 线跟手抖 / 贴格边闪 | 每帧按矩形包含重算路径 | 第二字前跟手切向；定方向后粘住角内不换向 |
| 4 | 线一格一格跳 | 预览线只画到选中格中心 | **看见的条**连续跟手；**收字**仍按最近中心 |
| 5 | 斜划时条短于手指、对不齐 | 画线用单位圆 `(0.71,0.71)`，`along` 按格步 `(1,1)` | **画线 step 必须等于投影 step**（对角 `(1,1)`） |
| 6 | 切到斜向时条突然变长 | 旧 `alongVisual` × 新 `(1,1)`；格步不是像素 | **每帧用当前射线重投影**。换向禁止沿用上一档 along |

命中用普通 `clientX/Y` 映射到格子网格。不要用 iOS `preciseLocation` 做进格。

## 三层反馈（不移动棋盘）

| 阶段 | 看见 | 震动 |
|------|------|------|
| 按下 | 本次色、直径 0.75、不透明，在**字下面**；按下格立刻变白；当前格放大 | transient I0.55 S0.86 |
| 滑动 | 条沿当前 8 向伸到手指在该线上的最近点（仍 0.75）；每新字母：字弹、胶囊更新 | 每新字母 transient I0.25 S0.64 |
| 抬手成功 | 同色留下 0.7；扩散淡出；字飞到词表再划掉 | 找对 pattern（TUNE.md） |
| 抬手失败 | ≥2 格未成词：晃动淡出；一格/死区/cancel 当取消 | 错误三记 / 取消不震 |
