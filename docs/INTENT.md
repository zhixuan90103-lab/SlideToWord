# 意图识别 — Slide to Word

配套：[CONVENTIONS.md](./CONVENTIONS.md) · [SWIPE.md](./SWIPE.md)

**状态：已接代码**（`model.ts` 放置索引 · `swipeDesign.ts` 柔和方向 · `mount.ts` 合同与终点门）。常数与 [SWIPE.md](./SWIPE.md) 同步。

对照：快滑也能流畅成交（类似键盘模糊完成），但词表是**本盘剩余直线词**，不是语言模型。关卡无关：禁止 `level.id` / 单词字符串特判。

---

## 1. 一句话

按下缩小范围。未到第二字 8 向立刻切；到达第二字才定方向并辅助。抬手用松手点量离词另一端有多近。差一截或过一点可以收；两个都像则不收。

```
按下  → 候选 = 剩余放置里，这一格是头或尾
滑出  → along < 1 不辅助；≥ 1 定方向后粘住 / 可贴向
抬手  → 松手点重投影；终点门按快/慢、欠/过分档
cancel→ 丢掉，不认词
```

## 2. 分层（勿混）

| 层 | 管什么 | 不管什么 |
|----|--------|----------|
| **合同** | 何时用哪一次触点更新 `along` | 认不认词 |
| **候选** | 任意盘上剩余词的头/尾放置 | 关卡剧情 |
| **方向** | 未过门槛不动；过了瞬间切。快滑门槛更高 | 时间延迟、条缓切 |
| **终点** | 离词另一端多近算收 | 改 8 向公式 |

几何真源仍只在 `swipeDesign.ts`。`mount.ts` 禁止再写一套投影；只决定：抬手再调一次 `moveSwipe`、何时对候选打分。

滑动中**预览**仍用 `round(along)`（条不吸到词上）。**成交**才走终点门。

## 3. 合同（尺子）

必须先于终点门。否则意图在给过期长度打分。

1. **`pointerup`**：用松手 `clientX/Y` 再跑一次现有投影，再用更新后的 `along` 做终点判定。
2. **`pointercancel`**：丢掉本次路径，**禁止**走成交。
3. **出盘**：仍把触点投到已锁射线上（capture 还在）。不要因 `localOnGrid` 失败冻住上一格。
4. **预测触点**（若以后接 iOS predicted）：只可辅助观感，禁止进成交；线头仍以真实触点在当前射线上的投影为准。
5. letterbox 外仍忽略（壳约定）。棋盘外、仍在射线延长线上：投影保留。

## 4. 候选（任意 `n×n`）

放置（placement）= 一词在盘上的一条线段：头格、尾格、单位步。同一字符串出现两次 = 两条放置。正划与反划是**同一条放置**。

按下格 `S` 后：

```
候选 = 尚未找到的放置 ∩（头 == S 或 尾 == S）
```

词从 `S` **中间穿过**不算。从 `KITE` 的 `I` 按下，候选里没有 `KITE`。

| 候选数 | 行为 |
|--------|------|
| 0 | 本次不模糊成交；字面 `matchWord` 若碰巧是词仍可收 |
| 1 | 定方向后可贴该放置；终点只对这一条开门 |
| ≥2 | 跟手；定方向后再按射线筛；仍 ≥2 且都进终点门 → 拒绝 |

实现：`locatePlacements(grid, remaining)`，按下只查表。不要按关卡号分支。

## 5. 方向（柔和，不锁死）

玩家明确换向必须能换（已滑两格也可以）。手指抖动、快滑被拉直，条不要闪。

**禁止**一次滑动锁死方向。缩回死区仍清方向（与 [SWIPE.md](./SWIPE.md) 一致）。

| 规则 | 规定 |
|------|------|
| 死区 | 仍 0.45 格：字母不外扩。条**跟手指方向**微伸 |
| 未到第二字 | `along < 1`：**不辅助**。8 向按 22.5° 中线立刻切 |
| 到达第二字 | `along ≥ 1`：用当前角度**确定方向**，然后才开辅助 |
| 协助 | 粘住、贴词向只在方向确定之后。快滑门槛更高防抖 |
| 换向 | 确定后：未过粘住角不动，过了**瞬间切** |
| 看见的条 | 与当前格步一致瞬间对齐。禁止单位圆（BUG 5） |
| 角度定义 | 仍是起点中心 → 手指。禁止矩形邻格抢锁、禁止折线 |

滑动中预览字母仍随当前射线的 `round(along)` 变，不把条吸到候选词两端。

---

## 6. 终点门（抬手）

禁止单一 `END_SLOP`。快滑易过冲，慢滑「刚过 3 个字母」不能当成 4 字词。用本次 `peakSpeed` 在慢/快两档间插值：

| | 欠程（没到终点） | 过冲（冲过终点） |
|--|------------------|------------------|
| 慢（≤4 格/秒） | 0.48 | 0.38 |
| 快（≥16 格/秒） | 0.95 | 1.25 |

另一端 `E`：若按下的是头，`E` 是尾；若按下的是尾，`E` 是头。

距离用**已锁射线**上的格数，不是手指到 `E` 的欧氏距离。

判定顺序：

1. 合同：松手点更新 `along` / 方向。死区内松手 → 不认词。
2. 字面：`round` 线段 ∈ 剩余词 → **直接收**，意图不覆盖。
3. 候选按当前射线筛选。
4. `err = |along − 步数|`，门槛 = `endSlopCells(peakSpeed, along > 步数)`。
5. 进门恰好 1 条 → 收。≥2 → **拒绝**。0 → 失败。

## 7. 不做

- 开放词库、FST、神经网络
- 关卡 / 单词特判
- 按下锁向、点一下成交
- 用放宽 `round` 或 `T = 0.5` 冒充意图（与现状相同）
- 一次滑动锁死方向
- Two Dots 拐弯、邻格抢锁、`preciseLocation` 进格
- 道具自动找词
