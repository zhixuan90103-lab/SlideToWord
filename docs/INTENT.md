配套：[CONVENTIONS.md](./CONVENTIONS.md) · [SWIPE.md](./SWIPE.md)

**状态：规范已定，代码未接。** 现行实现仍是字面 `round(along)` + 抬手不重投影。实现时以本文为准，并回改 [SWIPE.md](./SWIPE.md) 常数表。

对照：快滑也能流畅成交（类似键盘模糊完成），但词表是**本盘剩余直线词**，不是语言模型。关卡无关：禁止 `level.id` / 单词字符串特判。

## 1. 一句话

按下缩小范围，滑动柔和粘住方向（能换向、不锁死），抬手用松手点量离词另一端有多近。差一截或过一点可以收；两个都像则不收。

```
按下  → 候选 = 剩余放置里，这一格是头或尾
滑出  → 方向粘住、可换向；单候选可贴该词方向（不强迫）
抬手  → 松手点重投影；离唯一候选另一端 ≤ 门限 → 收
cancel→ 丢掉，不认词
```

## 2. 分层（勿混）

| 层 | 管什么 | 不管什么 |
|----|--------|----------|
| **合同** | 何时用哪一次触点更新 `along` | 认不认词 |
| **候选** | 任意盘上剩余词的头/尾放置 | 关卡剧情 |
| **方向** | 粘住、晚一点定、快滑更粘、条缓切 | 钉死一条射线 |
| **终点** | 离词另一端多近算收 | 改 8 向公式 |

几何真源仍只在 `swipeDesign.ts`。`mount.ts` 禁止再写一套投影；只决定：抬手再调一次 `moveSwipe`、何时对候选打分。

滑动中**预览**仍用 `round(along)`（条不吸到词上）。**成交**才走终点门。

## 3. 合同（尺子）

必须先于终点门。否则意图在给过期长度打分。

1. **`pointerup`**：用松手 `clientX/Y` 再跑一次现有投影，再用更新后的 `along` 做终点判定。
2. **`pointercancel`**：丢掉本次路径，**禁止**走成交。
3. **出盘**：仍把触点投到已锁射线上（capture 还在）。不要因 `localOnGrid` 失败冻住上一格。
4. **预测触点**（若以后接 iOS predicted）：只画 `alongVisual`，禁止进成交。
5. letterbox 外仍忽略（壳约定）。棋盘外、仍在射线延长线上：投影保留。

## 4. 候选（任意 `n×n`）

放置（placement）= 一词在盘上的一条线段：头格、尾格、单位步。同一字符串出现两次 = 两条放置。正划与反划是**同一条放置**。

按下格 `S` 后：

```
候选 = 尚未找到的放置 ∩（头 == S 或 尾 == S）
```

词从 `S` **中间穿过**不算。从 `KITE` 的 `I` 按下，候选里没有 `KITE`。

| 候选数 | 行为 |
|--------|------|
| 0 | 本次不模糊成交；字面 `matchWord` 若碰巧是词仍可收 |
| 1 | 方向可贴该放置；终点只对这一条开门 |
| ≥2 | 第一锁跟手；滑出后再按射线筛；仍 ≥2 且都进终点门 → 拒绝 |

实现：`locatePlacements(grid, remaining)`，按下只查表。不要按关卡号分支。

## 5. 方向（柔和，不锁死）

玩家明确换向必须能换（已滑两格也可以）。手指抖动、快滑被拉直，条不要闪。

**禁止**一次滑动锁死方向。缩回死区仍清方向（与 [SWIPE.md](./SWIPE.md) 一致）。

| 规则 | 规定 |
|------|------|
| 死区 | 仍 `LOCK_SLOP_CELLS`（0.35）。区内方向空，不贴词向 |
| 第一锁 | 刚出死区那一帧不定。再多走一点，或连续两帧同一 45° 档，再锁 |
| 粘住 | 已锁后小偏不当换向。门槛 ≥ 现 `OCTANT_HOLD`（约 28°），须大于 22.5° 中线 |
| 换向确认 | 新档要稳住约 2～3 帧（或等价短时间）才切。一帧尖峰不切 |
| 快滑 | 速度高则粘住加紧（更难被抖切走）。慢、刻意拐，照常能转 |
| 单候选贴向 | 出死区后第一锁优先该放置的 45°。玩家明显划向另一档则跟手，不拽回 |
| 多候选 | 禁止贴向，完全跟手 + 第一锁延迟 |
| 看见的条 | 换向时射线短跟随，禁止整根瞬切到邻档 |
| 角度定义 | 仍是起点中心 → 手指。禁止矩形邻格抢锁、禁止折线 |

滑动中预览字母仍随当前射线的 `round(along)` 变，不把条吸到候选词两端。

---

## 6. 终点门（抬手）

字面 `round(along)` 的成交窗是离终点中心 **0.5 格**。门必须 **> 0.5** 才叫意图。初值：

| 名 | 初值 | 含义 |
|----|------|------|
| `END_SLOP_CELLS` | **0.85** | 松手投影点沿射线离放置另一端中心 ≤ 此值则进门 |

另一端 `E`：若按下的是头，`E` 是尾；若按下的是尾，`E` 是头。

距离用**已锁射线**上的格数，不是手指到 `E` 的欧氏距离（避免斜向邻格抢终点）。

判定顺序：

1. 合同：松手点更新 `along` / 方向。死区内松手 → 不认词。
2. 字面：`round` 线段 ∈ 剩余词 → **直接收**，意图不覆盖。
3. 候选按当前射线筛选（放置的步与射线同向或反向）。
4. 对每条候选：`err = |along − 该放置步数|`（步数 = 字母数 − 1）。`err ≤ END_SLOP_CELLS` 进门。
5. 进门恰好 1 条 → 收该放置（条钉在头尾格心）。
6. 进门 ≥ 2 条 → **拒绝**。
7. 进门 0 条 → 失败，不惩罚。

过冲：多吃的下一格若**不是**另一条剩余放置的终点，仍可吸回当前词。若是，走第 6 步。

欠/过先**对称**。有实机 `along` 日志后再考虑欠更松。
