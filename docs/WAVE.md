# 过波 — 主题、种词、消落补

配套：[CONVENTIONS.md](./CONVENTIONS.md) · 真源：`src/game/wave.ts` · 接线：`src/game/mount.ts`

无尽波次，无失败。手势与意图见 [SWIPE.md](./SWIPE.md) · [INTENT.md](./INTENT.md)。

## 1. 一波是什么

- 词表上的词是**本波目标**。全部找到且飞字结束后才过波。
- 本波内：只划、不落。用过的字母等过波时**一起**消。
- 盘上词库里其它直线词也可收（额外词）：计分，字母本波留下，不消目标。
- 划空、划不成词：丢掉，不惩罚。

## 2. 目标个数与藏字

| 波次（内部 `waveIndex`，UI 不显示） | 目标数 |
|--------------------------------------|--------|
| 1–5 | 6 |
| 6–10 | 5 |
| 11–15 | 4 |
| 16+ | 3 |

`targetWordCount(wave) = max(3, 6 - floor((wave-1)/5))`

藏字母（下划线，每词最多藏 1 个；尽量不藏首尾）：

| 波次 | 藏几个词 |
|------|----------|
| < 20 | 0 |
| 20–24 | 1 |
| 25–29 | 2 |
| 30+ | 3 |

`maskedHintCount`。**重复主题**另算，见 §4。

## 3. 主题与词库

- 12 个主题（`WAVE_THEMES`）。橙条标题是线索；本波目标只从该主题抽。
- 额外词：`WAVE_LEXICON` = 全部主题词 ∪ `BONUS_EXTRA`（常用短词）。
- 额外词**不必**符合本波标题。
- 开局用 `createWaveLevel`，每局盘面不同。禁止再用固定 `TOY_STORE_LEVEL` 开局。

## 4. 重复主题

本局 `seenThemes`：每个已经**成功落地**的主题标题（含开局）。重置清空。

下一波 `planNextWave(grid, used, wave, avoidTheme, seenThemes)`：

1. **未用过**（标题不在 `seenThemes`，且 ≠ 上一波 `avoidTheme`）→ 种当前波次该有的个数，**不**全藏字。
2. 种不进去再放宽轴配额 / 最少词数。
3. 仍失败 → **重复**：已见过、且不是上一波的主题，强制 **6 个目标 + 每个词藏 1 个字母**（`maskAllHints`）。
4. 再失败 → 才允许**紧挨的上一波主题**，同样 6 + 全藏字。

因此「重复」不是「跟上波标题一样」，而是：**没用过的主题种不进去（或 12 个都见过）之后，回头用已见主题**。回头是为了多消格子，下一波更容易种进还没用过的主题。

## 5. 种词

- 目标两两不相交，禁止互相包含（TRAIN ⊃ RAIN）。
- 目标 ≥ 3 时轴配额：至少 1 横、1 竖、1 斜；多出来的词再摊。
- 先尽量钉在残留字母上，再穿过钉子写新字。
- 必须种满请求个数（或放宽后的 `minCount`）。禁止「凑满 3 个就算成功」。
- **禁止**把残留钉子当成已消除、整盘 `emptyGrid` 再从顶上掉下来。

## 6. 消 / 落 / 补

1. 只用过的格子清空。
2. 未用字母按列：下面有空才落，没空不动。
3. 顶上只补空位，棋盘保持满。
4. 锁格（TripleMatch）：每格 `current` / `incoming`；目标永远是下一格；走出 **0.22** 格才放源格。匀速（约 70ms/格，缓 65ms）。
5. 下落只画在与棋盘对齐的浮层（`top/left` 百分比）。`ws-falling` 时格子字隐藏。禁止在终点格 `translateY` 飞（iOS / Chrome 不一致）。
6. 落定：浮层先贴整数格，下一帧撤浮层。不换棋盘 DOM。
7. 落地缓冲同一条 rAF：轻下沉 + 轻压扁，原点格子下边（`fallFeel.ts`）。

过波期间 `phase === 'wave'`，不可划。
